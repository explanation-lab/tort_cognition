# Final pilot narration recording script

Record these **116 unique clips** in numerical order in one continuous WAV or M4A. Each numbered entry is one final clip. Read only the blockquote under **READ ALOUD**. Do not say clip numbers, filenames, keys, notes or destinations. Leave about **3 seconds of silence between clips**; keep pauses within a clip comfortably under 2 seconds. Read numerals naturally as numbers. Keep the original master unchanged.

Approximately **914 spoken words**, **6.5–8.3 minutes of speech**, plus **5.8 minutes between clips** (about 12–14 minutes total, excluding retakes).

Story text comes from the current approved PowerPoint captions. Only layout whitespace is normalized; words and punctuation are preserved. Identical text is recorded once, even if used on several slides. Both construct orders and both spatial layouts are covered. Experiment-2-only story recording filenames use the `exp2_` prefix; the installer copies each file to the existing runtime destination(s).

No outstanding squirrel/alligator wording or role inconsistencies. Both experiments use Nora as actor and Eric as victim; the alligator escape wording is shared.
