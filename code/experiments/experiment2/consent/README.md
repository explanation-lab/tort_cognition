# Adult consent study

Eight victim-not-careless stories from Experiment 1, with two added slides before each loss. The first slide states the victim's knowledge. The second says either “I’m okay with that.” (`consent`) or “I’m not okay with that.” (`no_consent`). Each adult sees all eight cases in one between-participant condition.

## Materials

The saved case PowerPoints are now the source for slide order, captions and browser images. To refresh after editing them, run `python3 code/tools/refresh-consent-review.py` with `TORT_PRESENTATIONS_SKILL`, `TORT_RUNTIME_NODE` and `RUNTIME_NODE_MODULES` pointing to the bundled presentation runtime. It renders changed decks, preserves the PowerPoint bytes, updates the manifest and wording, and regenerates the browser study and gallery. Each render cache records its source deck hash, and each browser image and PowerPoint link has a content version to avoid stale downloads.

The latest edits move the spill statements after Cleo walks in and the squirrel statements after Eric starts tying his shoelaces. Rex says “throw my cookies,” and Milo's action caption names Milo. Every story slide, including the allocation reminder, now comes from the edited deck for that condition. The response statements remain matched across conditions.

- `materials.json` records the wording and insertion points extracted from the saved decks.
- `adults/configuration.js` is generated by `python3 code/tools/generate-adult-consent.py` from that source and `docs/scenarios.json` Experiment 1.
- `adults/slides/consent/` and `adults/slides/no_consent/` each contain eight complete editable case decks, copied from the original victim-not-careless decks with the two new slides inserted. Original source decks remain unchanged.
- Original story images and task portraits are copied without alteration into `adults/images/`. The study therefore uses local material paths throughout.
- `adults/assets-manifest.json` maps all 172 slides to the exact source deck, ordered slide number, caption and image hashes. `code/tools/build-consent-slides.mjs` created the initial draft from the baseline; use the refresh tool for subsequent manual edits so those edits are preserved.

Existing actor intentions, animal containment/lock checks, victim behavior, 8/2 starting counts and 8/0 outcomes are preserved. Both conditions receive the same knowledge statement, artwork, positioning, and sequence; only “not” differs in the response. The added slides duplicate the original scene and its white bottom caption box (1120 × 96 at 80, 604). Captions use centered Arial Bold: 27 pt for the longer knowledge statements and the original 30 pt for responses. This keeps the full approved wording inside the original box. `background_base_slide` in `materials.json` identifies the copied scene for each case.

Original cookie allocation, fault, and carelessness measures are preserved. A Yes / No / Don’t remember consent recall item follows both judgments in each case, with no correctness feedback. Main judgments retain the existing counterbalancing; story order is randomized. Review sessions and participant attempts have their own session namespace, separate from the existing carelessness studies.

The wind and squirrel cases assess stated acceptance of a natural loss. The other cases involve consent to a loss involving another person's conduct. Foreknowledge is identical across conditions; adding it may affect victim-carelessness ratings relative to the original baseline.

## Participant integration and data

`adults/index.html` uses the existing Explanation Lab client through a relative import. A new Console study must register exactly `consent` and `no_consent`, with version `adult-consent-1.0.0`, before participant collection. The entry rejects the existing victim-carelessness pilot's launch configuration. It uses the current adult pilot's consent, demographics, feedback, save/retry behavior, and completion redirect. Duration and payment copy currently match that pilot ($1.50 / approximately five minutes); confirm these against this longer version before recruitment.

Every row records `experiment: 2`, `condition`, `consent_condition`, `base_material_experiment: 1`, `base_material_condition: victim_not_careless`, version, judgment order, destination side, and scenario order. Case rows also record the exact knowledge/response text, full victim statement, and ordered slide IDs. Story response times include every added slide. Recall rows record the response, expected answer, and correctness, separately from the original case summaries.

This addition does not register a live Console study, change the carelessness pilot, or deploy participant collection.

## Checks

It checks exact matched wording and source preservation, asset/deck mappings, every condition/order/side combination, full completion and saved metadata, recall scoring, session isolation, and rejection of mismatched launches. Existing behavioral checks also apply to the two optional shared runtime settings.
